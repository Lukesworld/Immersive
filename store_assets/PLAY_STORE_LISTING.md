# Immersive — Google Play Store Listing & Compliance Package

- **App Title (30 chars max):** `Immersive – Fullscreen & Edge`
- **Short Description (76/80 chars):** `True zero-ADB fullscreen mode with elastic edge gestures & frosted sidebars.`
- **Target SDK:** Android 16 (API 36)

## Full Description
Experience your Android display without visual clutter. **Immersive** delivers true edge-to-edge fullscreen mode, translucent frosted-glass navigation sidebars, and spring-physics edge gestures—all without ADB commands, PC setup, or root access.

**Built for Fluidity & One-Handed Ergonomics**
- **Zero-ADB Fullscreen Mode:** Hide distracting system bars across reading, browsing, and gaming apps.
- **Elastic Spring-Physics Sidebars:** Velocity-tracked edge drawers and navigation pills that respond immediately to your touch with crisp haptic checkpoints.
- **Frosted Glass & Dynamic Styling:** Real-time hardware blur on Android 12–16 with smart battery-saver fallback and Material You emerald accents.
- **Automatic Keyboard Recovery:** Bottom edge controls collapse the instant your keyboard opens so typing is never blocked.
- **Accessibility-First Controls:** Generous 48dp+ touch hitboxes, adjustable edge-zone sensitivity, and high-contrast WCAG AAA legibility.

**Privacy & AccessibilityService Notice**
Immersive uses the Android AccessibilityService API solely to render fullscreen overlays, perform edge-swipe system navigation (Back/Home/Recents), and detect keyboard state changes. Zero personal data, keystrokes, or screen contents are collected or shared.
